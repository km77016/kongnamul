서비스 가이드

등급 기준, 수수료 정책, API 문서를 한 곳에 정리했어요

API 엔드포인트
메서드경로기능
POST/api/auth/send-code이메일로 인증코드 발송 (회원가입용)
POST/api/auth/verify-code인증코드 검증
POST/api/auth/signup회원가입 (인증 완료 필요)
POST/api/auth/login로그인
POST/api/auth/logout로그아웃
GET/api/state시세·재고·잔액·보관함·피드 전체 조회
POST/api/trade구매(buy) 실행 (로그인+CSRF 필요)
POST/api/sell/request매입 신청 생성 (로그인+CSRF 필요)
GET/api/sell/my내 매입 신청 내역 조회
POST/api/sell/<id>/cancel매입 신청 취소 (submitted 상태만)
POST/api/deposit/request계좌이체 충전 요청 생성 (로그인+CSRF 필요)
GET/api/deposit/my내 충전 내역 조회
POST/api/portfolio/<id>/sell보관함 아이템 즉시 매도 (로그인+CSRF 필요)
POST/api/portfolio/<id>/deliver보관함 아이템 배송 신청 (로그인+CSRF 필요)
아래는 관리자 전용이에요 (admin 세션 필요, /admin에서 로그인)
GET/POST/api/admin/inventory모델·등급별 재고 조회/수정
GET/POST/api/admin/settings스프레드·수수료·갱신주기 조회/수정
POST/api/admin/users/<id>/suspend계정 정지/해제
POST/api/external_ref외부 참고시세 값 갱신 (scraper.py 연동용)
POST/api/tick_now정기 시세갱신을 수동으로 즉시 실행
POST/api/resetDB 초기화
서버는 30초마다 자동으로 do_tick()을 실행해서 시세를 갱신해요. 운영 환경에서는 app.py의 TICK_SECONDS 값을 늘리고(예: 하루 3회), scraper.py로 수집한 값을 /api/external_ref에 주기적으로 POST하면 돼요.
